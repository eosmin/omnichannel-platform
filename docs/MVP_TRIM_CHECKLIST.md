# MVP Trim Checklist (TDD v1.2)

> Companion to `INDEX.md` → "MVP scope". It lists, file by file, what an executor must **omit
> or adjust** when a TDD file describes something the single-owner MVP does not build.
> Where a TDD file and this checklist disagree, this checklist wins.
>
> Method: every file in `docs/` was read in full, line by line (2026-10-24): `TDD_00` to
> `TDD_15`, `IMPLEMENTATION_PLAN.md`, `INDEX.md` and `AUDIT_TDD_v1.0.md` (a historical record
> whose findings were already applied in v1.1; it adds nothing to this list). A hit this list
> still misses is covered by the INDEX rule: if the TDD describes a deferred feature, do not
> build it, and if that leaves something dangling, stop and ask (`CLAUDE.md` rule 12).

Items marked **APPROVED** were approved by the owner on 2026-10-24; the decisions D1 to D16 in
§7 are approved too. Everything removed here has a way back: see §6.
